# TrustRent: Project Work Distribution & Team Roles

This document outlines the official distribution of work and the specialized roles for the TrustRent Rental Marketplace project.

## 🛡️ Team Overview

| Member | Primary Role | Key Domains |
| :--- | :--- | :--- |
| **Shlok Dwivedi** | Backend & Deployment Architect | API, Database, Security, DevOps |
| **Pranav** | SRS & Frontend Lead | Requirements, Map System, i18n |
| **Pranay** | UI/UX & Presentation Lead | Interface Design, Dashboard UX, PPT |
| **Madhura** | QA, Analytics & PPT Lead | Testing, Landlord Analytics, Documentation |

## 🛡️ Task Breakdown

### 1. Backend & Infrastructure (Shlok)
- Development of the Flask-based RESTful API using a Blueprint-modular architecture.
- Full integration with Supabase (PostgreSQL, Storage, Row Level Security).
- Implementation of the Secure Auth System (OTP, JWT, Aadhaar Hashing).
- Deployment of the platform to Render (Backend) and Vercel (Frontend).

### 2. System Analysis & Core Frontend (Pranav)
- Authoring the comprehensive Software Requirements Specification (SRS v1.0.0).
- Architectural setup of the React/Vite frontend environment.
- Implementation of the Property Search system and Leaflet Map integration.
- Coordination of the Internationalization (English/Hindi) system using i18next.

### 3. User Experience & Presentation (Pranay)
- Design of the visual identity (Glassmorphism, Dark mode, Sleek UI).
- Creation of the high-fidelity Project Presentation (PPT).
- Development of the responsive Tenant/Landlord dashboards.
- Implementation of the real-time messaging UI and interaction logic.

### 4. Quality, Analytics & Documentation (Madhura)
- Co-authoring the Project Presentation (PPT) with a focus on business logic.
- Leading the Quality Assurance (QA) phase, including unit and integration testing.
- Implementation of the Landlord Analytics dashboard (Visualizing earnings/bookings).
- Drafting the User Manual and final technical project documentation.
