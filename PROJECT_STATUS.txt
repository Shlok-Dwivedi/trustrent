============================================================
 HOW TO RUN THE PROJECT
============================================================

Backend:
  cd trustrent/backend
  py run.py                    → runs on http://localhost:5001

Frontend:
  cd trustrent/frontend
  npm run dev                  → runs on http://localhost:5173
  (proxies /api/* → backend)

============================================================
 ONE-TIME SETUP (Supabase — do these ONCE)
============================================================

Step 1 — Run the main DB schema:
  1. Go to https://supabase.com → your project → SQL Editor
  2. Open: trustrent/backend/migrations/schema.sql
  3. Paste the entire file into the SQL Editor
  4. Click "Run" — this creates all tables

Step 1b — IMPORTANT: Run the missing tables migration:
  1. Open: trustrent/backend/migrations/002_missing_tables.sql
  2. Paste into Supabase SQL Editor and run
  This creates: reviews, notifications, messages tables (all needed for
  reviews, notification bell, and messaging to work)

Step 2 — Create the photo storage bucket:
  Option A (Easiest — UI):
    1. Supabase dashboard → left sidebar → Storage
    2. Click "New bucket"
    3. Name: listing-photos
    4. Toggle "Public bucket" ON
    5. Click Create
    (RLS policies are in create_storage_bucket.sql if you need them)

  Option B (SQL):
    1. Supabase → SQL Editor
    2. Open: trustrent/backend/migrations/create_storage_bucket.sql
    3. Paste + Run

Step 3 — Fill in .env files:
  backend/.env:
    SUPABASE_URL=https://xxxx.supabase.co
    SUPABASE_SERVICE_KEY=your_service_role_key
    JWT_SECRET_KEY=any_long_random_string
    SECRET_KEY=another_random_string
    FAST2SMS_API_KEY=optional_for_real_sms
    REDIS_URL=optional

  frontend/.env:
    VITE_API_URL=http://localhost:5001
    VITE_SUPABASE_URL=https://xxxx.supabase.co
    VITE_SUPABASE_ANON_KEY=your_anon_public_key

  (Supabase keys are in: Supabase dashboard → Project Settings → API)
